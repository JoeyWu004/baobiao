# 报表助手小程序

辅助经销商/安装商制作报表的微信小程序，基于微信云开发。

## 功能

- **微信授权登录**：默认直接进入小程序，登录态（7 天）过期时弹出提示一键重新登录；按微信账号（openid）隔离各自数据，可退出切换账号
- **商品库**：维护商品（名称 / 单位 / 进货价 / 销售价 / 供应商），支持搜索、增删改
- **自定义多级分类**：分类层级与名称完全自定义（如 卧室→挂壁、厨房→落地），商品可挂到任意深度的分类路径
- **发票识别**：上传供货商发票/送货单图片，用 Kimi 视觉模型自动识别商品明细（名称/数量/单价/金额），确认页核对后可一键存入商品库或开报表
- **库存数量**：商品有库存数量，可手动调整、发票导入累加、报表保存自动扣减；数量变动有记录（来源：手动/发票/报表）
- **多单位**：一个商品可有多个单位（如线材：桶/米），各单位独立价格与库存；开单时商品行可切换单位并自动带价
- **进货统计**：发票导入入库会生成进货记录，「我的」页可查看按月汇总的进货金额
- **新建报表**：选商品自动带出单位与销售价，可临时改价；可添加「工时费」明细；自动算金额与合计
- **改价联动**：开单时若改了销售价，自动同步回商品库并记录价格历史；在商品库改价也会记历史
- **报表交付**：小程序内查看 / 存为图片发微信 / 导出 Excel / 复制文本
- **位置信息**（可选）：开单时调用微信位置 API（`wx.chooseLocation`）选点，自动带出坐标和具体地址，展示在报表/导出中，地图 tab 可查看所有位置
- **报表状态**：每张报表有「待完成 / 进行中 / 已完成」状态，报表页**左滑**切换；地图 tab 用灰/橙/绿三种颜色标记
- **回收站**：报表页**长按**报表弹出菜单删除，删除进回收站；「我的」页可恢复或彻底删除

## 技术结构

```
miniprogram/
  pages/
    goods/goods       进货 tab（商品库列表）
    goods/edit        商品新增/编辑
    report-edit/      新建报表（核心）
    report-list/      报表 tab（报表历史，右下角「＋」新建）
    report-detail/    报表详情（存图 / 导出 / 复制）
    price-history/    商品价格历史
    map/              地图 tab（展示报表位置，按状态着色）
    profile/          我的 tab（当前用户 + 回收站入口 + 退出登录）
    trash/            回收站（恢复 / 彻底删除）
    category/         分类管理（自定义多级分类）
    category-goods/   某分类下的商品列表
    invoice/          发票上传识别
    invoice-confirm/  发票明细确认（入库/开报表）
    quantity-history/ 商品数量变动记录
    purchases/        进货统计（按月汇总）
  components/goods-picker/  商品选择弹层
  components/category-picker/  多级分类选择弹层
  utils/              工具与云函数封装、Canvas 绘制
cloudfunctions/
  userOps/            微信登录（openid）+ 用户资料
  reportOps/          报表事务保存 + 历史查询
  exportExcel/        生成 Excel 上传云存储
  invoiceOCR/         发票图片 Kimi 视觉识别
```

底部菜单栏（tabBar）：**报表**（报表历史）｜**进货**（商品库）｜**地图**（报表位置）｜**我的**（当前用户/退出登录）。

数据库 7 个集合：`users`（用户）、`categories`（分类）、`products`（商品）、`reports`（报表）、`priceHistory`（价格历史）、`quantityHistory`（数量变动）、`purchases`（进货记录）。所有数据按 openid 隔离，每个用户只能看到自己的数据。

## 首次配置步骤（必须手动完成）

1. **填环境 ID**：打开 `miniprogram/app.js`，把 `globalData.env` 里的空字符串改成你的云开发环境 ID。
   环境 ID 获取：微信开发者工具 → 右上角「云开发」→ 开通/进入环境 → 复制环境 ID。

2. **创建数据库集合**：云开发控制台 → 数据库 → 新建集合，共 7 个：
   - `users`
   - `categories`
   - `products`
   - `reports`
   - `priceHistory`
   - `quantityHistory`
   - `purchases`
   每个集合权限都设为「**仅创建者可读写**」。

3. **部署云函数**：在开发者工具左侧文件树中，分别右键
   - `cloudfunctions/userOps` → 上传并部署：云端安装依赖
   - `cloudfunctions/reportOps` → 上传并部署：云端安装依赖
   - `cloudfunctions/exportExcel` → 上传并部署：云端安装依赖
   - `cloudfunctions/invoiceOCR` → 上传并部署：云端安装依赖
   - **配置发票识别密钥**：部署时在云函数配置里设置环境变量 `KIMI_API_KEY`（必填，月之暗面 API key）；`KIMI_MODEL` 可选（默认 `moonshot-v1-8k-vision-preview`，用 Kimi K3 可改成对应模型 ID）

4. **配置隐私授权**：登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) 小程序后台 →
   「设置」→「服务内容声明」→「用户隐私保护指引」，声明 **「相册（仅写入）」** 和 **「位置信息」**，
   并开启「用户隐私保护指引」的隐私弹窗。不配置的话「存为图片」会报隐私错误、「定位」无法使用。

## 使用流程

0. 进入小程序直达「报表」tab；登录态过期时弹出提示，点「去登录」一键重新登录
1. 底部「进货」tab → 新增商品（录入名称 / 单位 / 进货价 / 销售价 / 供应商）
2. 底部「报表」tab → 点右下角「＋」新建报表 → 填客户、日期 → 「添加商品」搜索选择，自动带出单位与售价 → 改数量/单价 → 需要安装服务就「添加工时」→ 保存
3. 报表列表 → 打开详情 → 存为图片发给客户 / 导出 Excel / 复制文本
4. 已保存的报表可修改：详情页点「编辑报表」→ 改客户/日期/明细/金额后保存，改价同样会联动商品库并记历史

## 常见问题

- **提示「尚未配置云环境」**：按第 1 步填 `app.js` 里的 env ID。
- **登录失败**：确认 `userOps` 云函数已部署、「users」集合已创建。
- **保存/加载失败**：确认已创建 4 个集合、权限为「仅创建者可读写」、云函数已部署。
- **存图/定位失败提示隐私**：按第 4 步在 mp 后台配置「相册（仅写入）」和「位置信息」。
- **导出 Excel 提示云函数未部署**：右键 `cloudfunctions/exportExcel` 上传并部署。
